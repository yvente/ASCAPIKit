# Offline OpenAPI tooling

Use `python3 asc_openapi.py --help` for commands. The full installation, Apple ZIP hash pins and phase order are documented in the batch root `README.md` (not installed in repository).

`verified-typed.json` intentionally begins empty. Only enter an operation after reviewing its real Swift method, path, HTTP verb, request/response contracts and tests; descriptors and raw HTTP do not qualify as type-safe coverage.
